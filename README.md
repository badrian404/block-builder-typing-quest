# Block Builder Typing Quest

A blocky, building-themed typing game that teaches kids proper finger placement.

**Play it:** https://badrian404.github.io/block-builder-typing-quest/

- **Finger Camp** – 20 lessons, one or two new keys at a time, with stars to unlock the next lesson
- **Build School** – type real building tips to build 7 animated scenes (cozy home, railroad crossing, train station, redstone machine, ice castle, secret base, spooky cave)
- **Silly Speed Run** – funny sentences that use all 26 letters, ranked Wood → Diamond
- **Story Book** – write stories and have them read aloud
- **Protect the Villagers** – type the words on silly mobs to snowball them into snacks; 20 levels that follow Finger Camp, with a joke to unlock on every level
- **Typing music** – each correct letter plays the next note of a song (note block, piano, music box, bells, flute, clarinet or 8-bit)

Every key is coloured by the finger that should press it, and the hands show which finger to use next.
Works best on a computer with a real keyboard. Progress is saved in the browser.
